## 2023-10-27 - Context-Aware Screen Reader Announcements in Dynamic Carts
**Learning:** In highly dynamic components like POS and customer order carts, standard icon-only buttons (like `+` or `-`) lack sufficient context for screen reader users, especially when multiple identical items appear in a list. Additionally, simple text updates for quantity values go unnoticed by assistive technologies unless explicitly marked.
**Action:** When implementing list-based shopping carts or order summaries, always use context-aware `aria-label`s that interpolate the specific item's name (e.g., `aria-label="Decrease quantity of Wagyu Burger"`). For the numeric quantity display, wrap the value in a container with `aria-live="polite"` and `aria-atomic="true"` to ensure every update is clearly announced without overwhelming the user.

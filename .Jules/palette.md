## 2025-04-02 - Accessible Dynamic List Actions
**Learning:** In the BarNest POS and Customer Order views, dynamic list items (like cart contents) often use icon-only action buttons (minus, plus, trash) to modify quantities. These buttons previously lacked context, making it impossible for screen reader users to know *which* item they were modifying (e.g., they just heard "button, minus"). Additionally, the dynamic quantity display wasn't announced when updated.
**Action:** When implementing interactive list items, always use context-aware `aria-label`s that interpolate the item's name (e.g., `aria-label="Decrease quantity of ${item.name}"`). Apply `focus-visible:ring-2 focus-visible:ring-brand-secondary focus-visible:outline-none` for keyboard accessibility, and add `aria-live="polite" aria-atomic="true"` to containers displaying dynamic numeric values (like quantities) so updates are announced accurately.

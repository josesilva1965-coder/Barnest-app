## 2024-05-19 - Accessible Dynamic List Items in Carts
**Learning:** Icon-only buttons inside dynamic list items (like cart rows) need context-aware `aria-label`s that interpolate the item's name (e.g., "Decrease quantity of Wagyu Burger" rather than just "Decrease quantity"). Additionally, spans that display numeric quantities that change dynamically must use `aria-live="polite"` and `aria-atomic="true"` to ensure screen readers announce updates accurately. Focus visible styles (`focus:ring-2 focus:ring-brand-secondary focus:outline-none`) are also crucial since these buttons receive high keyboard interaction.
**Action:** Always interpolate item names into ARIA labels for list items and use `aria-live` containers for dynamic numerical values. Add visible focus indicators to all interactive elements.

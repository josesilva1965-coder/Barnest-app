## 2024-05-24 - Context-aware ARIA labels in dynamic lists
**Learning:** Action buttons inside dynamic lists (like cart items with increase/decrease/remove quantity buttons) need context-aware `aria-label`s. Without interpolating the specific item's name (e.g., `aria-label="Decrease quantity of Margherita Pizza"` instead of just `aria-label="Decrease"`), screen reader users hear multiple identical "Decrease" buttons and lose context of which item they are modifying. Additionally, containers displaying dynamic numeric values (like cart quantities) should use `aria-live="polite"` to ensure screen readers announce updates.
**Action:** Always interpolate the item's name into the `aria-label` for action buttons within iterative lists. Also, use `aria-live="polite"` on the quantity element itself so changes are announced.

## 2024-05-14 - Context-Aware ARIA Labels in Dynamic Carts
**Learning:** Icon-only buttons in dynamic lists (like "Decrease", "Increase", or "Remove" in a shopping cart) can be confusing for screen reader users if they all have the same generic `aria-label` (e.g., "Increase quantity"). This makes it impossible to know *which* item's quantity is being modified. Furthermore, dynamic updates to numeric values like cart quantities require `aria-live` to ensure screen readers announce updates.
**Action:** Always interpolate the item name into `aria-label` attributes for list item actions (e.g., `aria-label={"Increase quantity of " + item.name}`). Always add `aria-live="polite"` to containers displaying dynamically changing text/numeric values. Ensure icon-only buttons also receive keyboard focus classes (e.g., `focus:ring-2`).

## 2024-05-25 - Dynamic Cart Accessibility
**Learning:** Icon-only action buttons within dynamic list items (like increase/decrease/remove quantity buttons in a cart) require context-aware `aria-label`s that interpolate the item's name (e.g., "Decrease quantity of Wagyu Burger") to ensure clear feedback for screen reader users. Additionally, containers displaying dynamic numeric values (like cart quantities) must use `aria-live="polite"` and `aria-atomic="true"` to ensure screen readers announce updates accurately when the value changes.
**Action:** When implementing shopping carts or similar dynamic lists, ensure that any icon-only action buttons include an `aria-label` that provides context about the specific item being modified, and wrap dynamic values in an `aria-live` region.

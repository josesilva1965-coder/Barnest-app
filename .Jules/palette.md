## 2026-03-25 - Context-Aware ARIA Labels for Dynamic Cart Items
**Learning:** Icon-only buttons in dynamic lists (like cart quantity controls) require context-aware `aria-label`s that interpolate the item name (e.g., "Decrease quantity of Classic Mojito") rather than generic labels (e.g., "Decrease quantity"). Otherwise, screen reader users cannot easily distinguish which item they are interacting with when tabbing through the cart. Additionally, numeric containers updated by these buttons need `aria-live="polite"` to ensure the new quantity is announced upon change.
**Action:** When creating or reviewing components with dynamic interactive lists (like carts or schedules), ensure all icon-only action buttons include interpolated `aria-label`s containing the item's identifier, and use `aria-live` on the resulting state display.

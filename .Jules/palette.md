## 2024-03-14 - ARIA labels in dynamic list actions\n**Learning:** Action buttons within dynamic list items (e.g., increase/decrease/remove quantity in a cart) must use context-aware `aria-label`s that interpolate the item's name to ensure clear feedback for screen reader users.\n**Action:** Add aria-labels with interpolated names to list action buttons in PosScreen.tsx and CustomerOrderScreen.tsx.

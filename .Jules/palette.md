## 2024-03-24 - Accessibility improvements for dynamic list item buttons
**Learning:** Icon-only buttons inside dynamic lists (like cart items in `PosScreen.tsx` and `CustomerOrderScreen.tsx`) are confusing for screen reader users without context. Using a generic label like "Increase quantity" on multiple items makes it hard to know *which* item is being targeted. Screen readers also need a `aria-live="polite"` attribute on numeric values that update dynamically to announce the changes.
**Action:** When adding icon-only buttons to dynamic lists, ensure the `aria-label` interpolates the item's name (e.g., `` `Increase quantity of ${item.name}` ``). Additionally, include a visible focus indicator (e.g., `focus:ring-2 focus:ring-brand-secondary focus:outline-none`) so keyboard users can navigate these elements easily. Apply `aria-live="polite"` on containers displaying dynamic numeric values.
